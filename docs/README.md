# Documentation map

Three public-record files. Consolidated 2026-08-09; superseded originals remain available
in git history rather than being duplicated here.

| file | contents |
| --- | --- |
| [`RESEARCH_RECORD.md`](RESEARCH_RECORD.md) | the scientific record: canonical narrative, methods, results, limitations, roadmap |
| [`PROVENANCE_AND_REFERENCES.md`](PROVENANCE_AND_REFERENCES.md) | DAG/data lineage, ACIC lineage, the Reynolds DAG handoff, annotated references and claim-to-citation map |
| [`REPRODUCIBILITY_AND_SITE.md`](REPRODUCIBILITY_AND_SITE.md) | environments, build/validation commands, public-site integration and content discipline |

Documentation rule: every substantive result states its estimand and
intervention semantics, graph and data regime, evidence status (teaching /
matched comparison / prototype), computational budget, and uncertainty
procedure. Public claims settle in `RESEARCH_RECORD.md` before reaching the
site.
